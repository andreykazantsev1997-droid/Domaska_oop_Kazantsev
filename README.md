# Домашняя работа на тему ООП

## Учебный проект, который реализует логику работы классов.

### Установка и запуск проекта:
1. Клонируйте репозиторий:
   ```
   git clone https://github.com/andreykazantsev1997-droid/Domaska_oop_Kazantsev.git
   cd domashka_oop
   ```
   
2. Установите зависимости через Poetry:
   ```
   poetry install
   ```
   
3. Запуск демонстрационного скрипта
Для проверки работы классов и демонстрационного вывода запустите файл из корня проекта:
    ```
    poetry run python 16.1_main.py
    ```
   
В данном проекте функциональность сложения реализована таким образом, чтобы можно было складывать 
товары только из одинаковых классов продуктов. 

Так же функционал добавляет продукт в категорию, таким образом, 
чтобы не было возможности добавить вместо продукта или его наследников любой другой объект с помощью функций: 
```
isistance()
issubclass()
```
